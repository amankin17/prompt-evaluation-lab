# Prompt Evaluation Lab — LLM Response Quality & Business Use Cases

**Focus:** prompt engineering · evaluation design · qualitative-to-quantitative scoring · business analysis

A reproducible, **offline** benchmark for business-oriented prompt templates. It compares concise vs. structured prompting on a small synthetic response fixture and generates a scorecard. The mock responses are **not generated by a live LLM** and results do not measure any provider/model.

## Why this matters
Teams adopting GenAI need repeatable ways to assess whether responses meet a business task's requirements, instead of judging prompts by intuition.

## Run
```bash
python src/evaluate.py
python -m unittest discover -s tests -v
```

Prints prompt-variant scorecards for synthetic examples and saves nothing by default. Standard-library only.

## Evaluation dimensions
- **Coverage**: required terms or deliverables found in output.
- **Grounding**: output avoids fabricated numeric claims absent from the task context.
- **Format adherence**: requested JSON parses and contains required keys.
- **Actionability**: output includes a decision/recommendation or next step.

## Production extension
Connect a real model API behind an adapter, capture consent-safe annotated test cases, evaluate semantic accuracy with expert review, and track cost/latency and drift. Never treat keyword checks as equivalent to factual correctness.

## Portfolio talking points
Explain how the evaluation rubric maps vague stakeholder requests into testable acceptance criteria, and where automatic grading fails.
